# Assignment Overview

In this assignment, I solved 8 problems using TypeScript. I learned many new concepts and got some practical experience. I practiced functions, arrays, tuples, union types, generics, interfaces, classes, and inheritance. I also learned about Promises and async/await. This assignment helped me understand TypeScript better.

## Technologies & Concepts Used

- **TypeScript** – Main programming language.
- **Type System** – Types and type safety.
- **Generics** – Reusable functions.
- **OOP** – Classes and inheritance.
- **Async Programming** – Promises and async/await.

## Task Challenges and Learning

### Task 01: Multiplication with Optional Parameters
I used optional parameters and if-else conditions to handle different values. I also handled zero and undefined values.

### Task 02: Input Processing with Union Types
I used union types to accept different values. I also used `typeof` and `never` for type checking.

### Task 03: Coordinate Formatting with Readonly Tuple
I used a readonly tuple to store coordinates and a location name. I used destructuring to get the values.

### Task 04: Array Concatenation Using Generics
I created a generic function to combine multiple arrays using rest parameters and `concat()`.

### Task 05: Filtering Courses with Interfaces
I used an interface and filter conditions to find published courses with enough students.

### Task 06: Extracting Object Properties with Generics
I used `keyof` and generics to get object property values safely.

### Task 07: Object-Oriented Programming with Inheritance
I created Employee and Manager classes. I practiced inheritance, constructors, access modifiers, and getters.

### Task 08: Asynchronous Age Validation with Promises
I used Promises, async/await, `resolve`, `reject`, and `setTimeout()` to check age and handle different results.
